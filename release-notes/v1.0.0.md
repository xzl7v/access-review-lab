Access Review Lab helps reviewers trace repository access before and after an offboarding decision.

- Replay JSON scenarios, timestamped CSV exports, or read-only GitHub role captures.
- Review a batch, compare capture snapshots, and open the source records for each path.
- Verify original CSV and GitHub capture files against the evidence packet in the browser.
- Export filtered cases as CSV and individual review briefs as Markdown.

The workspace includes synthetic cases for retained access, verified removal, and evidence gaps.
